FlexTimer PWA v2

UI changes:
- Timer display now dominates about 80% of the phone screen.
- Removed 1/5/10/25 minute preset buttons.
- Removed font selector UI.
- Uses grotesque-style typography (Archivo + Space Grotesk).
- Keeps only custom hours/minutes/seconds input plus Start/Pause/Reset.
- Keeps notification/vibration logic from the supplied app.
- Service worker cache bumped to v2.

INSTALL:
The ZIP itself cannot be installed as a PWA. The files must be served from HTTPS.
After hosting them, open the HTTPS URL in Chrome and use Chrome's install/Add to
home screen option when it is offered.
